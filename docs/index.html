TripWardrobe — mock-сервер каталога

Учебный REST-сервис для приложения «Цифровой гардероб и сборка чемодана» (вариант 15, дисциплина «Разработка приложений для iPhone и iPad», ГГТУ им. П. О. Сухого).

Приложение обращается к этому адресу при каждом запуске и наполняет локальную базу данных SwiftData, сохраняя данные пользователя.

МетодПутьОписание
GET /api/catalog.json Каталог сезонов, образов и вещей гардероба
