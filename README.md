# TripWardrobe — цифровой гардероб и сборка чемодана

Учебный проект по дисциплине «Разработка приложений для iPhone и iPad»
(ГГТУ им. П. О. Сухого, кафедра «Информационные технологии»).

**Вариант 15** — мобильное приложение для планирования цифрового гардероба и сборки
чемоданов в поездки с функцией расчёта веса багажа.

Выполнил: студент группы ИТП-41 Сеноженский В. В.
Преподаватель: Шаблинский Д. А.

## Технологии

| Слой | Решение |
|---|---|
| Язык | Swift 5.9 |
| Интерфейс | SwiftUI, iOS/iPadOS 17 |
| Архитектура | MVVM |
| Хранение | SwiftData + UserDefaults |
| Сеть | URLSession + Combine |
| Генерация проекта | XcodeGen (`project.yml`) |
| Сборка и тесты | GitHub Actions, macOS-раннер |

## Состояние по лабораторным работам

Каждая лабораторная работа зафиксирована отдельной веткой, `main` содержит
последнее состояние проекта.

| Ветка | Лабораторная работа | Содержание |
|---|---|---|
| [`lab1`](../../tree/lab1) | ЛР № 1 | Пользовательский интерфейс средствами SwiftUI: иерархия «Сезон/Стиль → Образ → Вещь», поиск и фильтрация по статусу |
| [`lab2`](../../tree/lab2) | ЛР № 2 | Архитектура MVVM: карточка поездки с расчётом веса багажа и автоматическое формирование списка вещей |
| [`lab3`](../../tree/lab3) | ЛР № 3 | Хранение данных: SwiftData и UserDefaults |
| [`lab4`](../../tree/lab4) | ЛР № 4 | Сетевое взаимодействие: REST API, Combine, экспорт чек-листа |

Отчёты лежат в каталогах [`lab1`](lab1), [`lab2`](lab2), [`lab3`](lab3), [`lab4`](lab4).

## Сборка

Устройства Apple для разработки не используются: проект собирается и тестируется
на виртуальных машинах macOS сервиса GitHub Actions.

```bash
brew install xcodegen
xcodegen generate
xcodebuild test -scheme TripWardrobe \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro'
```
